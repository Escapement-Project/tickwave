Reading a debug port's ID over SWD

A probe opens an SWD session with a line reset, holding SWDIO high while it clocks. It then sends the JTAG-to-SWD select sequence, resets the line again, and reads the debug port's ID register. That read starts with a request the probe drives and the target's acknowledge. Later in the same capture the target answers WAIT to a read it is not ready for.
