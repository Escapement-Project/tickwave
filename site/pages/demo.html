A capture in a page

A page can cite a capture the way it cites a figure. Each underlined phrase below names a stretch of a real capture. Point at one, or reach it with Tab, to see that stretch. Click it to open the whole capture there.

A probe opens an SWD session

A logic analyser recorded this at a billion samples a second, so one tick is one nanosecond. The debug probe starts with a line reset: it holds SWDIO high for 51 clocks. Then it sends the JTAG-to-SWD select sequence and resets the line again.

Its first transfer reads the debug port's ID register. The probe drives the request. The target drives the acknowledge and the data. Later on, the target answers WAIT to a read it isn't ready for.

Here is the whole capture, closed. Its line says what it holds before any of its data downloads. Open it to zoom, place cursors and measure.

The same kind of bus, on analog inputs

This capture comes from a mixed-signal analyser's two analog inputs, at a billion samples a second. The analyser read each sample as an integer code, and the recording stores those codes. One code step is about 2.5 mV, so a readout stops at the millivolt. Place two cursors on a trace to read its voltage at each.

How this page does it

The page includes one script. The capture and its annotations sit beside the page as files: identify-swd.chrono, and a sidecar of annotations that names each stretch the text cites.

<script type="module" src="chrono.js"></script>

<p>Its first transfer <chrono-ref for="capture" annotation="dpidr-read">reads
the debug port's ID register</chrono-ref>.</p>

<chrono-inset src="identify-swd.chrono" annotations="identify-swd.annotations.toml"
              annotation="dpidr-read"></chrono-inset>

<chrono-view id="capture" src="identify-swd.chrono"
             annotations="identify-swd.annotations.toml"></chrono-view>

The sidecar is a short TOML file. This entry gives a name to a transfer that an SWD decoder found, and asks the inset to measure the clock over it:

[[annotation]]
id = "dpidr-read"
ref = "swd/read/377094557"
label = "Reading the debug port's ID register"
measure = { channel = "SWCLK", what = "rate" }

A reference loads nothing until it scrolls into view. Then it fetches the recording's head and the sidecar. The data for a stretch arrives when someone points at it. The elements lists every attribute, and the sidecar its fields.
